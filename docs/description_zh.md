# 琉璃 (Glazuli)

琉璃改的是你进游戏前后一直盯着看的那些地方：加载画面、主菜单和各种界面。纯客户端模组，装着它也能进任何服务器。

## 启动动画

红底的 Mojang 画面还在，加载完以后会播放 Mojang Studios 的标志动画和音效。接着标志变透明，镜头从中间穿过去进入主菜单场景，Minecraft 标题再一个字母一个字母落下来。用过 LabyMod 的人应该一眼就能认出来是照着它做的。按任意键可以跳过。

切换资源包、换语言或者按 F3+T 重载时，也是同样的红底画面，不会再闪出原版的加载条。退出游戏时画面渐黑。

第一次进入主菜单会先播一小段音效，播完才开始放菜单音乐。这段音效取自 C418《Minecraft》开头的四个音，改成了比较轻柔的版本。想换成自己的，把 startup.ogg 放进 config/glazuli 就行。

## 主菜单场景

原版的全景图换成了真正的 3D 场景。每打开一个不同的菜单，镜头就换一个位置；进入世界时镜头会一路冲进去。

自带的场景有：洞穴、繁茂洞穴、深暗之域、冰窟、下界、海底废墟、黄昏的平原村庄、夜晚的雪原村庄、沙漠村庄、远古城市、试炼密室、堡垒遗迹、末地城。村庄这些建筑是用游戏自己的结构文件拼出来的，和你在世界里见到的一样。装了机械动力的话，还会多一个机器在转的工厂场景。

也可以自己做场景。在世界里找个喜欢的地方站好，输入 /menuscene save <名字>，周围的方块会存进 config/glazuli/scenes，并直接设为主菜单背景。在主菜单点「场景」按钮就能来回切换。

室外场景的昼夜跟着电脑时间走，晚上七点打开游戏看到的就是日落。开着 Iris 光影的话，场景也会用你的光影包来渲染。

## 液态玻璃界面

面板、按钮、滑块、提示框、聊天栏、右上角的通知、Boss 血条和物品栏都换成了磨砂玻璃，能透出并模糊后面的画面，边缘还有一点折射。按钮按下去会轻轻压扁，切换界面时会淡入淡出。

只想要动态背景的话，点主菜单右上角的按钮就能把界面换回原版。暂停菜单里还有一个单独的开关，管的是进入世界以后的界面，所以可以菜单用玻璃、游戏里用原版物品栏，反过来也行。

装了改界面贴图的资源包也没问题，资源包的贴图会原样显示，只保留动画效果。

像素字体换成了鸿蒙黑体，系统装了苹方就用苹方。想用别的字体，把 .ttf、.otf 或 .ttc 文件放进 config/glazuli/fonts 即可，也可以直接关掉自定义字体。

## 模组适配

- **钠 (Sodium)**：视频设置界面换成了玻璃风格，基于 Reese's Sodium Options 改的。
- **Iris**：主菜单场景会用你的光影包渲染，Iris 自己的界面按钮也是玻璃的。
- **JEI**：面板、按钮和搜索框。
- **Jade**：屏幕上方的方块信息提示框。
- **机械动力**及其附属：界面加上玻璃面板，另外多一个工厂场景。

其他模组加在主菜单上的按钮都会保留。

## 设置

每项功能都能在模组设置里单独关掉（模组列表里选琉璃，点「配置」）。如果显卡带不动模糊，把「模糊质量」调低或者关掉就行。

第一次启动时，琉璃会把原版的「菜单背景模糊度」设成 0，好让场景保持清晰。想要模糊效果的话，去辅助功能设置里调回来就行，之后不会再被改掉。

## 运行环境

- Minecraft 1.21.1
- NeoForge 21.1
- 可选：钠 0.8.13 及以上（低于 0.9）、Iris、JEI、Jade、机械动力
